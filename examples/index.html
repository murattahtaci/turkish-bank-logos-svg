Türkiye banka ve ödeme kuruluşu logoları — örnekler

35 banka ve 5 ödeme / elektronik para kuruluşunun orijinal SVG logoları, üç kullanım biçimiyle; her logonun koyu zemin için düz beyaz bir sürümü de var. Kaynaklar, lisanslar ve marka uyarısı: github.com/murattahtaci/turkish-bank-logos-svg

1. <img>

<img src="svg/garanti.svg" alt="Garanti BBVA" style="height:24px">        <!-- açık zemin -->
<img src="svg-white/garanti.svg" alt="Garanti BBVA" style="height:24px">  <!-- koyu zemin -->

2. CSS sınıfı

<link rel="stylesheet" href="bank-logos.css">
<span class="bank-logo bank-logo--garanti" role="img" aria-label="Garanti BBVA"></span>

/* koyu tema: sayfanızın CSS'inde, kullandığınız her logo için */
[data-theme="dark"] .bank-logo--garanti { background-image: url("svg-white/garanti.svg"); }

Yükseklik 24 px; .bank-logo{height:32px} ile değişir. Genişlik logonun kendi oranından gelir. Her kutuda üstte açık zemin (svg/), altta koyu zemin (svg-white/).

3. JS — banka adından logo

import { findBankSlug, bankLogoUrl } from './index.js';

findBankSlug('T. GARANTİ BANKASI A.Ş.');                // 'garanti'
bankLogoUrl('T. GARANTİ BANKASI A.Ş.');                 // '…/svg/garanti.svg'
bankLogoUrl('T. GARANTİ BANKASI A.Ş.', 'svg-white/');   // koyu tema: 'svg-white/garanti.svg'
findBankSlug('BİLİNMEYEN BANKA A.Ş.');                  // null — logo yok, adı yazın
